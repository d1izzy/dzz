# Портфолио — full-stack разработка

React 19 / Vite / Tailwind. Контент и контакты находятся в `src/data`.

## Локальная работа

- `npm ci` — установить зависимости по lock-файлу.
- `npm run dev` — разработка на http://127.0.0.1:5173.
- `npm test` — проверки формирования заявки и ссылки Telegram.
- `npm run build` — production-сборка в `dist`.
- `npm run preview` — проверить сборку на http://127.0.0.1:4173.

Главная страница: `/`. Документы: `/privacy`, `/terms`. Vercel и Netlify настроены на возврат `index.html` для этих маршрутов. Для публикации в подпапке задайте `BASE_PATH` при сборке и соответствующий rewrite на хостинге.

## Графика и адаптивность

На экранах от 1024 px глобус загружается отдельно после первого отображения страницы. Золотая сфера, точки, дуги и ручное вращение сохранены. Плотность пикселей ограничена, рендер останавливается вне экрана и при скрытии вкладки. При уменьшении движения в настройках устройства глобус остаётся неподвижным.

На небольших экранах 3D-модуль не загружается. На устройствах с сенсорным вводом, при экономии трафика и уменьшении движения используются снимки кейсов; на компьютерах живые превью работают только пока видны. Фоновые лучи и частицы включаются на больших экранах с мышью и при обычном режиме движения.

Зерно — статичная текстура. Искры запускаются по нажатию и не расходуют кадры в простое. Появление секций использует браузерные анимации. Циклические эффекты учитывают видимость и настройку уменьшения движения.

`GlobeRenderer` создаёт экземпляр того же `globe.gl` внутри эффекта с обязательным уничтожением. `build/globe-lifecycle.mjs` освобождает временные экземпляры слоёв внутри установленной `three-globe` 2.45.2; это устраняет её фоновые таймеры. Исправление применяется в dev и production без изменения `node_modules`. При обновлении библиотеки проверка шаблона останавливает сборку, если этот участок изменился; тесты проверяют освобождение временных экземпляров.

## Форма

Собственного сервера заявок нет. Форма подготавливает текст и открывает Telegram; отправку подтверждает посетитель в мессенджере. Введённые поля сохраняются до закрытия или перезагрузки страницы. При заблокированном окне можно повторно открыть чат или скопировать текст. Секреты и токены для формы не нужны.

## Проверка перед публикацией

Проверить 320–390 px, планшет 768 px, ноутбук 1024 px и desktop 1440 px, а также низкий горизонтальный экран. Проверить Tab/Shift+Tab/Escape в мобильном меню, изменение ширины с открытым меню, форму с заблокированным всплывающим окном, уменьшенное движение, прямые ссылки на документы, консоль без ошибок. Внешние превью зависят от доступности сайтов кейсов.

Стенд `http://127.0.0.1:5173/tests/browser.html?run=1&reduce=1` выполняет проверки формы без отправки: Telegram и буфер обмена заменены тестовыми обработчиками. Есть переключатель reduced motion и счётчик выполненных callbacks `requestAnimationFrame` (это не показатель FPS). Параметр `production=1` запускает уже собранный код из `dist`; сначала выполнить `npm run build`. Стенд не входит в production-сборку. Для полной проверки CSS-настроек reduced motion нужно также включить уменьшение движения на устройстве/в браузере.

Изменения публикуются только после одобрения владельца. Перед коммитом проверить его Git author/email; не добавлять соавторов. Обновление GitHub может запустить автоматический деплой Vercel, если интеграция включена.
